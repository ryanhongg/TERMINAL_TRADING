# Portfolio Intelligence

An interactive portfolio analysis and visualization project.

## Overview

Portfolio Intelligence is a web-based project designed to present portfolio information through an interactive dashboard. Positions and prices are entered manually and stored in your browser only. Nothing is sent to a server.

## Features

* Interactive portfolio dashboard with sector and holding allocation
* Manual position entry, inline price editing, and bulk paste import
* ETF look-through exposure (direct plus indirect exposure to each company)
* Options tracking with Black-Scholes values, Greeks, and payoff charts
* Stress tests with preset and custom market scenarios
* Financial metrics and performance summaries (unrealized P&L, option delta, concentration insights)

## Usage

Download or clone this repository and open `index.html` in your browser.

## Notes

* Prices are not live. Values are only as current as what you enter.
* Pre-filled ETF holdings weights are approximations. Replace them with current data from your fund issuer.
* Option values are theoretical estimates. Analysis is hypothetical and not financial advice.
